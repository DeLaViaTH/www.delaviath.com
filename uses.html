What I use

An honest list of the things I actually use while learning — not a wishlist, and not everything I have ever installed. If something is new to me, it says so.

Hardware

Laptop
One MSI machine running Windows 11. It is the only computer I have, so everything here was built and tested on it.
IoT board
An ESP32 and a drawer of jumper wires. I'm at the stage of getting one sensor to report a number reliably.

Development

Editor
VS Code. I lean on Copilot more than I probably should while I'm still learning the syntax.
Comfortable with
HTML and CSS. These are the parts I can sit down and write without looking much up.
Getting better at
JavaScript — especially reading errors and understanding why something works, not just that it does.
Have used, still learning
React, Next.js and a little Python. I've finished tutorial-sized projects in each, not production work.
Terminal
Windows Terminal with PowerShell. Enough to run commands and fix my own mistakes.
Version control
Git and GitHub. Still learning what a useful commit message looks like.

Hosting

Hosting
Cloudflare Pages, because it is free and deploys when I push. This site lives there.
Domain and DNS
I bought a domain and pointed it at Cloudflare myself — the first time I'd done it without a guide.
Status page
A monitoring page set up from an open-source Workers template, mostly to learn how it works. See it here →
Self-hosting
A couple of services on my own computer, purely to see how they behave when I run them.
This site
Hand-written HTML and CSS with no framework — the clearest way I've found to learn layout.

Things I'm trying to get right

Finish one thing
Better to complete a small project badly than to start five and finish none. I'm still working on this.
Read the docs
The answer is usually in the documentation, and reading it properly is faster than guessing.
Write it down
If I had to work something out twice, it goes in a note — otherwise I'll work it out a third time.
Say what I actually know
It is more useful to be clear about what I can and can't do yet than to sound impressive.
